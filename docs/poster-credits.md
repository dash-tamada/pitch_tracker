# Login poster wall — image credits

Classic Telugu film posters behind the sign-in page (`public/img/posters/`), 1933–1961.

Under the Indian Copyright Act a cinematograph film — and the publicity material published with it — is
protected for 60 years from publication, so films released in 1965 or earlier are in the public domain
in India. Each file below is tagged **Public domain** (or **CC0**) on Wikimedia Commons; the license column
is copied from each file's Commons metadata at download time. Check a file's Commons page before reusing it
outside this app. Modern Telugu film posters are deliberately not used: they are still under copyright.
